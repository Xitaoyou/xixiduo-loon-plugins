# 常用服务检测

长按 Loon 节点列表中的一个具体节点，在工具菜单中选择「检测常用服务」。此入口已由用户确认可用；不需要从首页脚本列表查找。更新插件后，再从此入口运行。

## 设置

- 检测范围：core 检测 GitHub、ChatGPT、Claude、Gemini；all 检测全部 13 项服务。
- 检测路径：current 按当前分流规则；DIRECT 强制直连；也可填写准确的节点/策略组名称。从长按菜单启动不会自动使用被长按的节点，只有这里指定后才会强制使用它。Loon 对无效名称的回退无法由脚本核实。
- 查询 IP 类型与质量：默认开启。关闭后仅检测服务，不请求 IP 数据源。
- 超时：每次请求默认 10 秒，整轮预算 100 秒。最多 4 项任务并行。仅手动执行，没有后台轮询，不修改你的节点和分流。

## 显示

弹窗仅显示 IP、网络类型、质量参考，以及每项服务的应用图标、名称、状态、已知地区和耗时。地区未知时省略；来源、风险字段与解释保留在此文档，不占用弹窗。报告不重复弹窗标题，不使用表格和背景样式，适配 Loon 的原生 HTML 显示。图文效果以实际 Loon 为准。

## IP 质量的来源与边界

依据 FlClash 的 lib/common/ip_quality.dart 与 lib/models/ip_quality.dart 改写，优先通过 ident.me 确定本次查询 IP；失败时依次尝试 ipquery.io、ipify.org。必要时使用 ipquery.io、ipapi.is 查询该地址；全部使用 HTTPS。优先采用明确类型，住宅推断会特别注明。数据源限流、超时或不返回字段时显示未知；不把缺失的风险字段视为“没有风险”。公网 IP 查询最多三个来源，类型查询最多两个来源，串行失败回退，不做后台更新。查询会向上述第三方发送待检测公网 IP；无需账号或 API Key。

FlClash 的质量规则：Tor 或滥用标记为风险；机房类型为一般；住宅、移动、企业类型为优。界面用绿色“优”、黄色“一般”、红色“风险”、灰色“未知”展示，不是独立风险分数，也不保证解锁 AI、IP 无人滥用或账号安全。VPN/代理标记单独显示，没有加入新的打分逻辑。

current 模式中不同探测域名可能经过不同出口；卡片只显示 IP 查询请求看到的地址，不能代表所有 AI 或流媒体出口。想检查同一个指定节点，可把检测路径设为它的准确名称。

## 服务规则

检测逻辑参考 FlClash 的 core/service_check.go 与 core/service_rules.go。涵盖 Google、GitHub、YouTube Premium、ChatGPT、Claude、Gemini、Netflix、Disney+、Prime Video、Spotify、TikTok、Discord、哔哩哔哩番剧。

地区判断和页面标记会随上游变化；可达/规则通过不等于实际登录、聊天或播放成功。Loon 无法像 Go 内核那样流式截断响应，Gemini 等页面可能较大；默认 core 以减少请求。未实现 FlClash 的实际出站链路记录和自动重试。

## 来源与验证

检测脚本由西西多改写，沿用 FlClash 来源和 GPL-3.0-only 许可，见 scripts/service-check/COPYING。应用图标来自 luestr/IconResource，商标属于对应权利人。

已通过语法检查及 15 组模拟场景，包括服务状态、IP 类型与风险、缺失字段、IP 不匹配、HTML 转义、图标国旗和关闭 IP 查询。用户已确认原版长按入口可用；本次图文及 IP 更新尚待真实 Loon 验证。若异常，停用插件即可，不改原有分流。

Loon 当前公开插件接口没有向原生主页添加卡片的能力。本插件通过节点长按菜单显示报告。
