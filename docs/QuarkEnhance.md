# 夸克网盘增强 · 清晰度择优 + 直链抓取

## 这个插件做什么

**一条响应改写 + 一条请求探测**，全部只作用于本机 App 读到的数据：

| 规则 | 触发方式 | 改什么 |
| --- | --- | --- |
| 夸克响应改写 | 所有 `*.quark.cn` 响应，**按 body 内容判断** | 会员字段、清晰度排序、播放门禁位、并发数、限速字段、直链抽取、广告位清空，一次遍历办完 |
| 接口探测 | 所有 `*.quark.cn` 请求（默认关） | 记录真实调用的「方法 + 域名 + path」，第一次见到发通知 |

### 为什么只有一条改写规则

Loon 里同一条响应被前一个脚本 `$done` 之后，后一个脚本拿到的是**已经改过的 body**。拆成「会员」「清晰度」「并发」「去广告」多条规则时，正则一旦重叠就会互相抢——早前版本的 `speed` 规则抢走 `/ad/config`，导致去广告脚本永远不执行，就是这个事故。现在合成一个脚本：一次 `JSON.parse`、一次遍历、一次 `$done`，顺序问题从根上消失。

### 为什么按 body 判断而不是按 URL 路径

夸克换版本会改接口名。实测（`pan.quark.cn` / `drive-pc.quark.cn` / `drive-m.quark.cn` 三个入口都一样）：

| 路径 | 实际响应 |
| --- | --- |
| `/1/clouddrive/member` | 401 `require login [guest]`（存在） |
| `/1/clouddrive/config` | 401 `require login [guest]`（存在） |
| `/1/clouddrive/file/play` | 401 `require login [guest]`（存在） |
| `/1/clouddrive/file/download` | 405 Method Not Allowed（存在，POST） |
| `/1/clouddrive/vip/info`、`account/info`、`user/info`、`speed`、`setting`、`transcode/list`、`ad/list`、`banner/list`、`splash/config`、`operation/popup` | **404 Not Found** |

也就是说，按那些「看起来合理」的路径写正则，规则永远不会命中。所以脚本不看路径，只看 body 里认不认得那些字段名；认不出的响应当场 `$done({})` 原样放行，不会把页面改坏。

## 能做到和做不到的（重要）

这部分是实机结论，不是猜测。**先说不能**：

- **不能让服务端认为你是会员。** 账号权益由服务端按真实账号下发，脚本改的是 App 手里的 JSON。会员专属的**服务端签名**能力（离线缓存、超大文件直链、倍速的转码档）仍然拿不到。
- **不能突破 CDN 限速。** 桌面版同一条线路实测：游客通道单流 0.14–0.49 MB/s，4/8/16 并发 0.04–0.34 MB/s；登录转存后 32 连接 **47.7 MB/s**。瓶颈在「有没有登录 + 服务端给的会话签名」，不在并发数。把并发写到 64 反而掉到 1.7 MB/s，128 直接 0。
- **不能让没下发的清晰度出现。** 择优只在服务端已经给出的 `video_list` 里排序，4K 没下发就是没有。
- **抓到的直链通常很短命。** 免登录 `/file/share/download` 对超过约 50 MB 的文件返回 `23018 download file size limit`（5/10/19/42 MB 的文件都能过，399 MB 和 1000 MB 一律拒绝）；`/file/download` 对分享 fid 返回 `31001 require login [share missing]`。直链还绑同会话 Cookie，换个客户端或换个 UA 直接 412。

**能做到**：

- 客户端自己判断的门禁（`need_vip`、`locked` 放在 JSON 里让 App 决定）能翻过去，1080p 档能播。
- 会员入口、倍速菜单这类纯 UI 判断会按会员态显示。
- 已下发的最清晰度能排到第一位，不用手动切。
- 直链能抓出来丢给 nPlayer / aria2 / VLC 播放或下载。
- 开屏、首页 banner、活动弹窗的接口能清空。

## 安装

[点此一键导入 Loon](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2FXitaoyou%2Fxixiduo-loon-plugins%2Fmain%2Fplugins%2FQuarkEnhance.plugin)

或直接在 Loon 插件列表添加：

```text
https://raw.githubusercontent.com/Xitaoyou/xixiduo-loon-plugins/main/plugins/QuarkEnhance.plugin
```

需要 Loon 3.5.1 (998)+ 的新脚本语法、已启用 Rewrite/脚本、MitM 并信任 CA 证书。装完**完全退出夸克 App 再打开**，缓存里的旧响应不会重新走脚本。

## 插件设置（默认值）

| 参数 | 默认 | 效果 |
| --- | --- | --- |
| 会员态字段伪装 | 开 | 会员字段改成最高等级；关掉后恢复服务端原值 |
| 播放清晰度择优 | 开 | 已下发的清晰度按高度降序；关掉保持原始顺序 |
| 去掉播放门禁位 | 开 | `need_vip`、`locked` 翻 false，`can_play` 翻 true |
| 下载并发上限 | 32 | 客户端允许开多少连接，1–64。桌面版实测 32 最好 |
| 清掉限速字段 | 开 | `speed_limit`、`rate_limit` 清 0，限速开关翻 false |
| 抓取直链 | 开 | 直链存 `quark_links`（最多 40 条）；只收夸克自家域名或带媒体/文件扩展名的地址，头像和埋点不会被收进来；同一条直链重复出现不会重复弹通知 |
| 直链推送地址 | 空 | 填 `https://` 地址时把直链 POST 出去，body 是 `{"api": "...", "links": [...]}` |
| 清空广告位 | 开 | 广告接口的 `data` 换空壳；非广告接口上的 `banners` 也清内容 |
| 接口探测（排障用） | **关** | 记录真实接口路径，夸克改版本后用它补正则 |
| 排障日志 | **关** | 每次改写弹通知说明改了什么 |

## 怎么用抓到的直链

1. 打开「抓取直链」，播一个视频或点一次下载。
2. 通知里会显示抓到的条数和本地累计条数。
3. 想看全部：把 `scripts/quark/dump.js` 手动跑一次（或直接在宿主里读 `quark_links` 这个 persistentStore 键），它会打印一行一个 URL。
4. 复制给 nPlayer / VLC / aria2。注意直链有时效且绑会话，过一会儿就 412/403。

## 排查

1. **主插件看起来没生效**（会员入口没变、清晰度没变）：先打开「排障日志」，通知里会写这次改了什么；再打开「接口探测」，看通知里出现的真实路径。夸克换版本会改接口名和字段名，字段名族在 `rewrite.js` 顶部的 `VIP` / `LIST` / `CONC_F` 等数组里，照着通知里的新字段补一行即可。
2. **播放黑屏或转圈**：先关「去掉播放门禁位」。有些流服务端确实没给地址，翻标志位只会让客户端拿到空 URL 然后一直转。
3. **下载速度没变化**：正常。速度瓶颈是账号和 CDN 签名，不是并发数字。要看真实差距，用桌面版客户端对比登录前后（登录后 32 连接 47.7 MB/s，游客封顶约 0.3 MB/s）。
4. **抓到的直链打不开**：多半是会话过期或换了客户端。直链带 `__sdid`/`__pugs` 之类的会话 cookie，必须在同一会话里用。
5. **某个广告又出现了**：说明那个接口的容器名不在 `AD_KEYS` 里，也没命中 `AD_PATH` 的路径词。开探测，把新路径和容器字段名发出来即可。
6. **要关掉某个功能**：插件设置里对应开关关掉即可，不需要卸载插件；只有探测脚本默认就是关的。

## 与其他插件的关系

- 域名级广告拦截可以叠加本库的「广告平台补充拦截器」，两者不冲突：一个拦域名，一个清 JSON。
- 不要同时启用其他改写 `*.quark.cn` 响应的插件或脚本：本插件会接管这些响应，多个改写器叠加时后执行的拿到的是前一个改过的 body。
