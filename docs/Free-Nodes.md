# 免费节点订阅（试用）

作者：西西多。独立节点订阅，不替换现有配置、机场订阅或去广告插件。

## 添加与更新

[一键添加免费节点](https://www.nsloon.com/openloon/import?nodelist=https%3A%2F%2Fraw.githubusercontent.com%2FXitaoyou%2Fxixiduo-loon-plugins%2Fmain%2Fsubscriptions%2F%E5%85%8D%E8%B4%B9%E8%8A%82%E7%82%B9&name=%E5%85%8D%E8%B4%B9%E8%8A%82%E7%82%B9)，在安装 Loon 的 iPhone 上打开。已添加旧版的用户直接更新原订阅即可。

手动添加：在 Loon「订阅节点」中新建「免费节点」，粘贴下面地址。已经是 Loon 标准格式，不需要额外资源解析器。

```text
https://raw.githubusercontent.com/Xitaoyou/xixiduo-loon-plugins/main/subscriptions/%E5%85%8D%E8%B4%B9%E8%8A%82%E7%82%B9
```

导入链接附带名称并使用同名文件，但 Loon 官方没有承诺支持 `name` 参数；若未预填，首次填写「免费节点」即可。旧地址 `free-nodes.txt` 继续更新，已有名称不会强制修改。

云端每 6 小时计划检测并生成，手机端建议开启每天一次的订阅自动更新，无需开启电脑。也可在 Actions → Update free nodes → Run workflow 手动触发。GitHub 定时任务可能延迟；公共仓库长期无活动可能停用计划任务。

## 节点列表

顶部按下列顺序显示有合格结果的推荐项：

- `AI推荐：🇺🇸 美国 01`
- `备选AI：🇯🇵 日本 01`
- `流媒体推荐：🇸🇬 新加坡 01`
- `备选流媒体：🇺🇸 美国 02｜245ms · 17.86Mbps`
- `下载推荐：🇺🇸 美国 03｜98ms · 32.50Mbps`
- `备选下载：🇯🇵 日本 02｜140ms · 28.00Mbps`
- `纯净IP推荐：🇩🇪 德国 01｜282ms · 27.72Mbps`（仅有合格结果时显示）
- `🕒 免费节点刷新 11-09 18:38（北京）`

随后每个国家最多显示四个普通精选节点，例如 `🇯🇵 日本 01｜120ms · 20.00Mbps`。每国按 IP 质量优先、AI 请求延迟次之选择最多四个不同实际出口 IP，同分时参考下载速度。已标记风险、下载测速失败或 AI 不足两项通过的候选会过滤；质量未知的候选允许保留，但排在已确认低风险项之后；不足四个时只保留合格数量，不凑数，没有合格节点的国家不显示。AI/流媒体/下载推荐可以引用其他同国节点，但不会把该国全部候选展开。四个名额针对普通国家列表；推荐项可能另用同国的专用候选。推荐里出现的 02、03 等编号仍是同国不同连接，编号按本轮保留结果分配。IP 质量是分类及风险参考，不是对 IP 好坏的保证。常见地区使用中文，其他地区显示两字母代码。

名称末尾显示本轮实测结果：`ms` 是通过的 AI 项目请求耗时中位数，`Mbps` 是两次小样本下载吞吐中位数。下载失败的候选会过滤，不填 0 或虚构速度。

推荐项和刷新时间项都是已通过检测的真实节点别名，不是无法连接的占位项。同一连接可能同时出现在推荐、时间和普通列表中；状态文件中的 `nodes` 统计独立节点，`published_rows` 统计包含别名的行数。

时间为最近一次成功检测和生成的北京时间 UTC+8；失败时不更新时间。手机拉取后才能看到新时间。编号和推荐可能随本轮检测变化，请不要依赖固定编号长期绑定某个服务器。

## 收录与 AI 推荐

所有发布节点必须先通过 HTTPS 实际代理连接检测，并在 ChatGPT、Claude、Gemini 三项中至少两项通过；还必须通过下载测速，且没有已知 IP 风险标记。IP 质量查询失败或字段缺失的候选允许以「未知」保留。AI 未知、超时、挑战页面及地区受限均不算通过，IP 标记风险的候选不发布；未知质量不会推断为纯净。

AI 推荐依次比较：通过服务数（三项优先于两项）→ IP 质量 → 通过项目的 HTTPS 请求耗时中位数。主选、备选要求不同实际出口 IP；不足两个独立出口时只生成已有的合格推荐。

IP 质量通过公开的 IPQuery 接口查询本次实际出口 IP。响应 IP 必须匹配，字段必须完整；低风险非机房优于低风险机房，未知单独列出，已知代理/Tor/VPN 或高风险排后，再比较同类中的风险分数。查询失败或缺字段不推断为干净、住宅或低风险。出口 IP 会发送给该公开查询服务；同一 IP 在本轮缓存复用。

ChatGPT 判据为 iOS 端点预期提示加成功的合规 JSON；Claude 判据为官方 trace 的地区；Gemini 判据为网页地区标记。**这些是端点及地区推断，不证明账户登录、真实聊天或所有模型可用。**

## 纯净 IP 推荐

仅在实际出口 IP 与查询结果匹配、四个布尔标记字段完整、`risk_score = 0`，且 `is_datacenter`、`is_proxy`、`is_vpn`、`is_tor` 全部明确为 `false` 时，生成一条「纯净IP推荐」。仍须通过至少两项 AI 和下载测速。若有多个，优先三项 AI 都通过、再比较延迟等表现。

字段缺失、查询失败、风险非零、机房、代理、VPN、Tor 均不符合此推荐条件。没有合格结果时完全省略该推荐行，不用其他节点代替。这个名称仅表示符合 IPQuery 本轮的严格筛选条件，不代表绝对纯净、住宅 IP 或所有服务都信任。

## 流媒体推荐与下载测速

范围固定为 Netflix、Disney+、YouTube Premium、Prime Video。只有四项检测全部通过、且下载测速成功的节点才进入流媒体推荐候选，主备同样要求不同出口 IP。没有候选时不伪造推荐，不用仅网站可达的节点填充。

- Netflix：两个非自制剧的片目页需返回有效影视结构信息，不把 fast.com 可达或登录页视为解锁。
- Disney+：公开浏览器设备/令牌/会话流程返回支持地区；不登录用户账户。
- YouTube Premium：页面内容及地区限制提示。
- Prime Video：页面地区信息及受限提示。

对所有至少两项 AI 通过的候选，通过实际代理对 Cloudflare 下载端点做两次 2 MiB 测试，检查完整字节数、成功状态及 TLS 证书，取样本吞吐量中位数。流媒体主备仍只在四项流媒体检测都通过的节点中按 Mbps 从高到低选择；下载推荐及备选则在全部测速成功且未标记风险的候选中按速度选两个不同出口 IP，不要求流媒体四项通过；未知质量也可参与。只有一个合格出口时不凑备选。同速时参考质量和延迟。单节点测速负载为 4 MiB，全部在云端完成。

**流媒体检测不包含登录、付费账户和受 DRM 保护的视频播放，所以不能保证所有片库实际解锁。小样本测速也不是峰值带宽，GitHub 机房排序不等于你的手机速度。**

## 可靠性与使用

每次最多并行检测 4 个节点，不允许请求失败后直连回退。检测核心固定版本并核验官方 SHA256；节点域名解析后固定一个公开 IP 试连，因此多 IP 节点可能被保守排除。只生成节点，不接受上游规则、脚本、DNS 或 Host 配置。

源站、解密、核心或整体验证失败时保留上次发布；相同收录策略下数量下降超过 75% 也保留旧版。切换收录或每国精选策略的首轮允许正常减少。旧版本不保证仍然在线，请结合刷新时间判断。[生成状态](../subscriptions/free-nodes.json)提供独立保留节点数量（`nodes`）、国家数（`country_count`）、普通精选节点数（`country_best_count`）、精简前 AI 合格数量（`ai_qualified`）、质量分类、逐项结果、速度与推荐记录。

所有检测通过仅代表云端当时的结果，手机端仍可能不可达。平时只去广告时保持原有规则模式及各用途策略组的 DIRECT；需要代理时再选节点。不要把本链接当作完整配置导入，也不建议对全部节点高频测速。
